# System Prompts & Categories

## The Story of AI Behavior

| Feature | Description |
| :--- | :--- |
| **What** | Configure the AI's "brains" and the categories it uses to organize data. |
| **Where** | **Settings > System Prompts**. |

## 1. Categories
Define the buckets for AI analysis.
*   **Sourcing**: Sources of applicants (e.g., LinkedIn, Agency).
*   **Analysis**: Categories for Skills/Traits (e.g., "Leadership", "Coding").

## 2. Prompts
*Advanced*: Edit the system instructions used by Gemini for parsing resumes and generating descriptions.
*   **Resume Parsing Prompt**: Instructions for extracting data.
*   **JD Generation Prompt**: Tone and style for job descriptions.
