## Short description

Employee self service for attendance, leave, pay, expenses, documents and development.

## Description

Hrive gives employees secure mobile access to everyday people operations. Use Employee Self Service to review attendance, request leave, view payslips, manage expenses and benefits, access documents, complete learning and performance activities, submit overtime and timesheets, answer surveys, manage shift requests and onboarding, and keep your employee profile current.

The native iOS and Android apps support secure biometric re-entry, push notifications, verified deep links, offline change queueing, camera and file attachments, native sharing, and reconnect synchronization while using the same permissions and policies as the Hrive web application.

## Privacy / permission rationale

- Camera and photo access: only when the user chooses to capture or attach receipts, documents or profile images.
- Notifications: optional employee alerts and workflow updates.
- Biometrics / device credentials: optional local app re-entry protection; biometric templates are never read or stored by Hrive.
- Files: only files the user explicitly chooses to save or attach.
- Network/device metadata: used to maintain connectivity state and register the current app installation for notifications.

Store privacy questionnaires must be completed using the production organization's actual data collection, retention, analytics and third-party processor configuration before submission. This document is release guidance and does not replace the organization's legal privacy policy.
