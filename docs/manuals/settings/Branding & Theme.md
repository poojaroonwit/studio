# Branding & Theme Settings

## The Story of Your Identity

| Feature | Description |
| :--- | :--- |
| **What** | Customize the visual identity of the platform. |
| **Where** | **Settings > Branding & Theme**. |

## 1. Application Identity
*   **App Name**: Change the browser tab title (e.g., "Acme Recruit").
*   **Logo**: Upload your transparent PNG/SVG logo to replace the default icon sidebar.

## 2. Color Theme
*   **Dark/Light Mode**: Toggle default preference.
*   **Brand Colors**: (If enabled) Set primary hex codes.
