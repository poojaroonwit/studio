# Webhook Management

## The Story of Connectivity

| Feature | Description |
| :--- | :--- |
| **What** | Send real-time data to other systems when events occur. |
| **Where** | **Settings > Webhook Management**. |

## 1. Creating Webhooks
1.  Click **"Add Webhook"**.
2.  **Endpoint URL**: The destination (e.g., Slack Workflow, Zapier).
3.  **Events**: Select triggers (e.g., `candidate.created`, `application.status_changed`).

## 2. Logs & Debugging
*   **History**: View past delivery attempts.
*   **Status**: Check for `200 OK` or match error codes.
