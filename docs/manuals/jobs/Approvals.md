# Job Management

## The Story of Role Definition

| Feature | Description |
| :--- | :--- |
| **What** | Creating and configuring the technical requirements and workflows for a vacancy. |
| **Who** | **Hiring Managers** (for editing requirements) and **Recruiters** (for full management). |
| **When** | During the initial hiring request and iteratively as the search evolves. |
| **Why** | To ensure the AI screening engine and human recruiters are aligned on the "Perfect Match" criteria. |
| **Where** | Under the **Positions** menu item in the main navigation. |
| **How** | 1. Go to **Positions** <br> 2. Select an Active Job <br> 3. Click **"Edit"** on Match Criteria <br> 4. Update Skills/Keywords <br> 5. Click **"Save"** to update Al scorings |

## 1. Assigned Roles
You can only see positions where you are listed as the **Hiring Manager** or a collaborator. This keeps your view clean and focused only on the talent you need.

## 2. Editing Requirements
You have permission to "Live Edit" the job description to ensure accuracy.
- **Match Criteria**: Adjust the **"Must-Have"** skills. If you find the AI is recommending candidates with the wrong focus, refining these keywords will instantly re-sort the candidate list.
- **Job Description**: Use the built-in AI assistant to help draft or improve the wording of your job posts to attract better talent.

## 3. How to Verify (Test Case)
To test requirement editing:
1.  **Navigate**: Open **"Positions"** and select a job you manage.
2.  **Act**: In the **"Match Criteria"** section, add a new keyword (e.g., "Python") and save.
3.  **Confirm**: Navigate to the **"Candidates"** list for that job. The AI Fit Scores should refresh, and candidates with "Python" in their resume should now rank higher.
