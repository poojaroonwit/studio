# Evaluation Configuration

## The Story of Scoring

| Feature | Description |
| :--- | :--- |
| **What** | Configure the criteria and forms used to rate candidates. |
| **Where** | **Settings > Evaluation Configuration**. |

## 1. Expertise Skills
Define the hard skills library.
*   **Groups**: Buckets like "Frontend", "Backend".
*   **Skills**: Specific tags like "React", "Node.js".

## 2. Personality Traits
Define the soft skills library.
*   **Groups**: Buckets like "Culture", "Leadership".
*   **Traits**: Indicators like "Empathy", "Resilience".

## 3. Scorecards
*   **Templates**: Create reusable interview forms.
*   **Rating Scale**: Define what 1-5 stars mean.
