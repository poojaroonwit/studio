# Native release scope

The first native release is Employee Self Service focused.

Included through the shared Hrive application:

- Employee portal home
- Attendance and attendance corrections
- Leave
- Payslips
- Expenses
- Benefits
- Documents
- Learning
- Performance
- Overtime
- Timesheet
- Surveys
- Team
- Shift requests
- Onboarding
- Employee profile and requests

The native shells use the same authorization and server-side access controls as Hrive web. Store signing credentials and release secrets are intentionally external to source control.
