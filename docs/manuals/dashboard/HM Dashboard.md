# Dashboard Overview

## The Story of Your Workspace

| Feature | Description |
| :--- | :--- |
| **What** | A centralized view summarizing all active hiring tasks and pipeline status. |
| **Who** | **Every User** (content is dynamically filtered based on your role and permissions). |
| **When** | The default landing page every time you log into the platform. |
| **Why** | To prevent critical hiring tasks from falling through the cracks and to provide a real-time pulse on recruitment progress. |
| **Where** | The **Home** page of the FitScan application. |
| **How** | 1. Log in to **Home** <br> 2. Locate **"My Tasks"** widget <br> 3. Click **"Pending Scorecard"** or **"Approve Job"** <br> 4. Complete the task <br> 5. Verify the task disappears |

## 1. My Tasks
## 1. My Tasks
The **"My Tasks"** widget is your primary command center. It lists:
- **Pending Scorecards**: Candidates you have interviewed but haven't submitted feedback for yet.
- **Interviews Today**: Quick access to today's scheduled sessions.

## 2. Pipeline Overview
Visually track candidates moving through stages for your specific roles. A quick glance tells you:
- How many fresh applicants are in the "New" queue.

## 3. How to Verify (Test Case)
To ensure your Dashboard is operational:
1.  **Navigate**: Click the **"Home"** icon.
2.  **Act**: Check the **"My Tasks"** widget for any pending scorecard evaluations.
3.  **Confirm**: Click on a task. It should navigate you directly to the relevant candidate's profile/scorecard. Once the action is finished, return to the dashboard to verify the counter has decreased.
