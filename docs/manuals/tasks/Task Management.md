# Task Management

## The Story of Getting Things Done

| Feature | Description |
| :--- | :--- |
| **What** | A personal Kanban board to track your daily recruiting activities. |
| **Who** | **Recruiters** and **Hiring Managers**. |
| **When** | Daily, to manage to-do lists, reminders, and follow-ups. |
| **Why** | To keep your workflow organized and ensure no applicant follow-up is missed. |
| **Where** | The **Tasks** item in the main navigation. |
| **How** | 1. Navigate to **Tasks** <br> 2. Click **"New Task"** <br> 3. Enter details (e.g., "Call applicant X") <br> 4. Drag task to **"Done"** when complete |

## 1. The Task Board
Your personal workspace is organized into columns (e.g., To Do, In Progress, Done).
*   **Drag & Drop**: Move tasks between columns to update their status.
*   **Filters**: Use the filter bar to view tasks by Priority (High/Medium/Low) or Due Date.

## 2. Creating & Editing Tasks
1.  **Create**: Click the **"+"** button or "New Task".
2.  **Details**:
    *   **Title**: Short description (e.g., "Review Portfolio").
    *   **Description**: Detailed notes.
    *   **Due Date**: Set a deadline to keep yourself accountable.
    *   **Priority**: Flag urgent items.

## 3. Customize Your Board
Make the board work for you.
1.  Click the **"Customize"** (Settings icon) button.
2.  **Toggle Columns**: specific status columns can be hidden or shown.
3.  **Color Coding**: (If enabled) Customize task card colors based on priority.

## 4. How to Verify (Test Case)
To test the task workflow:
1.  **Navigate**: Go to the **Tasks** page.
2.  **Act**: Create a task named "Test Task" with High Priority.
3.  **Confirm**: Verify the task appears in the "To Do" column with a red (High Priority) indicator. Drag it to "Done" and ensure it stays there.
