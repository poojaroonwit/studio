# Interview Management

## Orchestrating the Hiring Loop
While Hiring Managers focus on *conducting* interviews, Recruiters are responsible for *scheduling* and managing the logistics.

## 1. The Interview Dashboard
Navigate to the **Interviews** module to see a calendar view of all upcoming sessions.

| View | Purpose |
| :--- | :--- |
| **Calendar** | Monthly/Weekly view of all scheduled interviews to spot conflicts. |
| **List View** | Chronological list of upcoming events with status tags. |
| **Pending** | Requests from Hiring Managers that need a time slot confirmed. |

## 2. Scheduling an Interview
1.  **From applicant Profile**: Click **"Schedule Interview"** within the Actions bar.
2.  **Select Type**: Phone Screen, Technical Round, or Onsite.
3.  **Choose Interviewers**: Select team members (their calendar availability will sync if Outlook is connected).
4.  **Set Time**: Pick a slot and generate a meeting link (Teams/Zoom).
5.  **Send Invites**: The system sends calendar invites to both the applicant and the interviewers.

## 3. Managing Cancellations
*   **Reschedule**: Drag and drop the event on the calendar to a new slot. The system will ask if you want to send update emails.
*   **Cancel**: Click the event and select **"Cancel Interview"**. You must provide a reason (e.g., "applicant Withdrew").

## 4. Interview Kits
Ensure fairness by attaching an **Interview Kit** to the invite.
*   This includes the **Scorecard** and specific **Questions** the interviewer should ask.
*   Interviews see this kit immediately when they open the applicant's profile.
